    Neue Anleitungen werden zunächst lokal im Browser gespeichert. Auf dem PC mit Edge oder Chrome auf «Im GitHub-Ordner speichern» klicken und die vorhandene Datei C:\GitHub\arbeitsanleitungen\anleitungen.json auswählen und überschreiben. Anschliessend in GitHub Desktop Commit to main und Push origin wählen. Falls die direkte Speicherung nicht unterstützt wird, «JSON herunterladen» verwenden. Die Webseite ist öffentlich.
